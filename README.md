# Линия роста

Интерактивный сайт академии телемаркетинга с общей базой сотрудников и результатов.

## Открыть локально

Скачайте репозиторий и откройте файл `index.html` двойным кликом. Устанавливать программы и запускать сервер не требуется.

## Возможности

- регистрация и повторный вход по имени и фамилии без пароля;
- личные кабинеты сотрудников с курсами, тестами, заданиями и рейтингом;
- персональные метрики, графики компетенций, рабочий план, заявки и история результатов;
- кабинет администратора Никиты Монастырёва со списком всех профилей на разных устройствах;
- удаление сотрудников вместе с их историей результатов из общей базы;
- индивидуальный план по дням: диалоги, пакеты и потенциальные абоненты;
- фиксация сотрудником фактических результатов и принятых заявок;
- аналитика каждого сотрудника, выполнение плана, знания тарифов и динамика попыток;
- создание, редактирование, публикация и удаление учебных курсов и уроков;
- загрузка учебного текста из TXT/Markdown и добавление ссылок на материалы;
- готовый демо-курс «Сильный звонок» из четырёх наполненных уроков;
- создание, редактирование, предпросмотр и удаление тестов;
- выгрузка сотрудников, ежедневных планов и результатов в Excel;
- синхронизация профилей, тестов и результатов между устройствами через Supabase;
- локальная резервная копия в браузере при временном отсутствии сети;
- адаптивный интерфейс для компьютеров и смартфонов.

Сайт не записывает IP-адреса в базу обучения. Таблицы закрыты правилами RLS, браузер обращается к ним только через ограниченную серверную функцию. Сотрудники входят без пароля по имени и фамилии; администратор использует отдельный PIN-код, который проверяется на сервере.

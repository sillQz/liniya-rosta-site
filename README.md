# Линия роста

Автономный интерактивный сайт академии телемаркетинга.

## Открыть локально

Скачайте репозиторий и откройте файл `index.html` двойным кликом. Устанавливать программы и запускать сервер не требуется.

## Возможности

- регистрация и повторный вход по имени и фамилии без пароля;
- личные кабинеты сотрудников с курсами, тестами, заданиями и рейтингом;
- персональные метрики, прогресс, баллы опыта и история результатов;
- кабинет администратора Никиты Монастырёва со списком всех локальных профилей;
- просмотр аналитики каждого сотрудника;
- создание, редактирование, предпросмотр и удаление тестов;
- сохранение профилей, контента и результатов в браузере;
- адаптивный интерфейс для компьютеров и смартфонов.

> Профили сохраняются на устройстве пользователя. Для синхронизации сотрудников между разными компьютерами потребуется подключение общей облачной базы.

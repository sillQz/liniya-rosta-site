# Линия роста

Автономный интерактивный сайт академии телемаркетинга.

## Открыть локально

Скачайте репозиторий и откройте файл `index.html` двойным кликом. Устанавливать программы и запускать сервер не требуется.

## Возможности

- кабинет сотрудника и кабинет организатора;
- курсы, тест и учебные задания;
- аналитика навыков и результатов команды;
- создание учебных материалов;
- сохранение демонстрационного прогресса в браузере;
- адаптивный интерфейс для компьютеров и смартфонов.
